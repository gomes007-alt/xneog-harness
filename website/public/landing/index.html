xneog harness turns a single DeepSeek API key into a complete agentic development environment — browser GUI, headless CLI, subagents, workflows, skills and sandboxed tools. Composable down to the last plugin.

Install & run See features ↓
terminal
$npm install -g @xneog/dsh
$xneog-harness web
→ xneog-harness web: http://127.0.0.1:3080

Requires Node.js 22.19+ (or 24+) and a DeepSeek API key. You can also run from source with pnpm install && pnpm build && pnpm xneog-harness web.

Features

One environment, every surface.

The same agent loop powers a polished browser GUI, a headless terminal agent, and an automation SDK — all built from a single plugin graph.

Browser GUI

A full web workspace with sessions, conversation history, plan mode, goals, deliverables and a plugin inspector — served locally on 127.0.0.1.

Headless CLI

Run tasks straight from the terminal: xneog-harness --profile headless "task". Perfect for CI, scripts and automation.

Everything is a plugin

Every capability — tools, models, UI panels, skills, sandboxes — is a composable plugin. Add, swap or write your own.

Subagents

Delegate independent work to parallel subagents with fork and spawn models, then collect their reports.

Workflows

Fan work out across many agents with phased orchestration, then converge — no turn-by-turn babysitting.

Skills & tools

Bash, file editing, web search, image reading, todo, goals, plan mode — a rich tool surface with sandboxing and approval control.

Powered by your key

Bring your DeepSeek API key.

No lock-in, no separate billing. xneog harness talks directly to the DeepSeek API with your key, so you control cost and usage.

Quick start

From zero to agent in seconds.

1 · Set your key

Export your key, or enter it in the browser onboarding the first time you launch.

# macOS / Linux
export DEEPSEEK_API_KEY=sk-...
# Windows (PowerShell)
$env:DEEPSEEK_API_KEY="sk-..."

2 · Launch

Start the web GUI, or run one task headless.

xneog-harness web
# or one-shot:
xneog-harness --profile headless "run the tests"
FAQ

Questions, answered.

What do I need to run xneog harness?
Node.js 22.19+ or 24+, a DeepSeek API key, and a terminal. The web GUI runs entirely on your machine via 127.0.0.1 — nothing leaves your box except the model requests to the DeepSeek API.
Does it work on Windows?
Yes. Use npm install -g @xneog/dsh from PowerShell (7+ recommended) and run xneog-harness web. The shell tools use PowerShell, and the sandbox adapts to Windows ACLs and ConPTY. Node 22+ is required.
Is it really open source?
Yes, MIT licensed. You can fork it, rebrand it, vendor it and self-host it. See the repository for the full license and third-party notices.
Which models does it support?
DeepSeek-V4-Flash and DeepSeek-V4-Pro out of the box, configured through the official DeepSeek provider. Additional providers plug in as plugins.
Can I extend it?
Everything is a plugin: tools, models, UI panels, skills, sandboxes and providers are all composable rows. Write your own package and add it to a profile — no fork required.
